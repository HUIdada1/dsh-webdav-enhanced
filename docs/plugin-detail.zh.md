# WebDAV 同步

用一台 WebDAV 服务器把插件、技能和模型配置在几台机器之间对齐：一台配好，其余机器跟上。

## 怎么用

配置就在**本页下方**的「连接」里：

1. 填 WebDAV 地址、账号、密码，点「测试连接」。测试会依次验证 PROPFIND、MKCOL、PUT 与回读，并探测服务端是否支持 LOCK / If-Match。
2. 到「同步内容」勾选要同步的东西。默认插件 + 技能，模型配置默认关闭（避免 API Key 外泄）。
3. 到「同步方式」选方向与周期。默认双向、不定时。
4. 顶部「立即同步」可随时手动跑一次；结果显示上传 / 下载 / 错误条数。

## 记住三件事

- **密码不出本机**：写在 `$DSH_HOME/.webdav-enhanced/credentials.json`（0600），不进 cordis 配置、不上传远端，接口返回的配置里永远没有密码。
- **配置默认不同步**：`settings.yaml` 可能含密钥；要同步就显式打开，或用「只同步这些顶层 key」精确指定。
- **冲突不丢数据**：默认策略会下载远端版本，并把本机旧版本打包备份到 `$DSH_HOME/.webdav-enhanced/backups/`。

## 兼容的服务器

Nextcloud / ownCloud、坚果云（应用专用密码）、群晖 WebDAV Server、AList，以及任意 RFC 4918 实现。服务端不支持 LOCK / If-Match 时自动降级为软锁与冲突副本。
