# WebDAV 同步

用一台 WebDAV 服务器，把插件、技能和模型配置同步到你的所有机器：一台配好，其余自动跟上。

面板有两个入口，内容完全一致：

- **插件详情页**：插件 → 已安装插件 → WebDAV 同步，面板就渲染在详情页里，共 7 个页签。
- **设置弹窗**：左侧导航的「WebDAV 同步」，是同一套面板，随手可开。

第一次用，先点开面板里的「说明」页签过一遍，再走这三步：

1. **连接**：填地址、账号、密码，点「测试连接」。测试会依次验证 PROPFIND、MKCOL、PUT 与回读，并探测服务端是否支持 LOCK / If-Match。
2. **内容**：勾选要同步的东西。默认插件 + 技能，模型配置默认关闭。
3. **方式**：选方向与间隔，逐个页签点「保存」。想先看差异就回「概览」点「分析差异」，只出清单，不写任何东西。

## 记住三件事

- **默认全自动，不问冲突**：两端分叉时按修改时间、再按版本号裁决赢家，输家自动备份到 `$DSH_HOME/.webdav-enhanced/backups/`。日志里写明谁赢了，不需要人工处理。
- **密码不出本机**：存在 `$DSH_HOME/.webdav-enhanced/credentials.json`（0600），不进配置、不上传远端，接口也永不返回。
- **配置默认不同步**：`settings.yaml` 可能含密钥；要同步就显式打开，或用「只同步这些顶层 key」精确指定。

## 同步范围

- **插件**：profile 里带 `dsh.bundle` 标记的依赖项，按本地路径打包。
- **技能**：`$DSH_HOME/skills` 下每个含 `SKILL.md` 的目录整包同步。
- **配置**：`settings.yaml` 的顶层 key，默认关闭；`.credentials.yaml` 与 `apiKey` 等敏感项永不参与。

## 能看到什么

「概览」的进度卡显示阶段、百分比、上传/下载/合并/跳过/删除计数与当前条目，随时可取消；「日志」页签按级别与分类记录每一笔操作，可筛选、搜索、导出。

## 兼容的服务器

Nextcloud / ownCloud、坚果云（应用专用密码）、群晖 WebDAV Server、AList，以及任意 RFC 4918 实现。服务端不支持 LOCK / If-Match 时自动降级为软锁。
